## Agent WebSocket protocol (draft, `/ws/agent`; exam protocol on `/ws` unchanged)

- page -> server: `{"type":"agent_hello"}`, `{"type":"pick_folder"}`, `{"type":"start_agent","backend":"...","model":"...","cwd":"..."}`, `{"type":"turn_audio","format":"wav","data":"<base64>"}`, `{"type":"turn_text","text":"..."}`, `{"type":"permission_response","id":"...","allow":true|false}`, `{"type":"interrupt"}`, `{"type":"playback_done"}`
- server -> page: `{"type":"agent_backends","backends":[{"id","label","models":[{"id","label"}],"status":{"state","message"}}],"default":{"backend","model"}|null}`, `{"type":"agent_folder","path":"..."|null}`, `{"type":"agent_started","backend","model","cwd"}`, `{"type":"state","state":"idle"|"listening"|"thinking"|"speaking"}`, `{"type":"transcript","text":"...","final":true}`, `{"type":"agent_text","text":"..."}`, `{"type":"agent_tool","tool":"...","summary":"..."}`, `{"type":"agent_reply","text":"..."}`, `{"type":"agent_error","message":"..."}`, `{"type":"permission_request","id","tool","title","detail"}`, `{"type":"permission_closed","id"}` (the request was cancelled by an interrupt or restart; hide its prompt), `{"type":"tts_audio","format":"wav","data":"<base64>"}`, `{"type":"notice","text":"..."}`
